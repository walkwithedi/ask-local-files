# ask-local-files：找文件问 AI

[English](README.md)

在不能装软件的电脑上，拿本地文件问大模型。只需要 Python 3 和浏览器，接任何 OpenAI 兼容接口，回答附原文摘句并自动核对。

- 零安装：只用 Python 3 标准库，双击「双击运行」或运行一条命令，在浏览器里操作；页面不从网络加载任何东西。
- 自己选文件，整篇发送：在添加的文件夹里按文件名找出文件，选几个连同问题发给模型，不建向量库、不切块检索。
- 摘句核对：要求模型每个结论附原文摘句，回答结束后逐条核对摘句是否真在文件里，找不到的标出来，减少编造。
- 只连你配置的模型接口：公司内网的模型网关、自建的 vLLM 或 Ollama、公有云 API 都可以。已在用 OpenCode 时自动读取它的模型配置。

页面为中文。

## 目录内容

| 文件 | 说明 |
| --- | --- |
| `双击运行.desktop` | 启动图标，文件管理器中显示为「找文件问 AI」，双击打开网页界面。 |
| `ask_local_files.py` | 本机网页服务：文件名索引、取文字、调用模型接口。Python 3.8 及以上，只用标准库。 |

| `doc2kb_core.py` | 读取 docx、xlsx、pptx、doc、xls、ppt、eml、pdf 的解析核心，是 [walkwithedi/doc2kb](https://github.com/walkwithedi/doc2kb) 发行版的原样副本，版本见 `DOC2KB_VERSION`。 |
| `skills/` | 预装的 skill，见下方「skill」。 |
| `tests/` | 测试，只在开发时运行：`test_ask_local_files.py` 为服务端测试、`test_skill_scripts.py` 为预装 skill 脚本的测试（标准库 unittest），`ui.test.js` 为界面测试（需要 Playwright 与 Chromium）；`fake_model.py` 为测试用的模型接口，`fake_opener.sh`、`fake_picker.sh` 代替打开文件夹与选择文件夹的系统命令，`same_name_cases.json` 为服务端与页面共用的同名规则样例。 |

## 运行环境要求

- Python 3.8 及以上，支持 `fetch` 与流式读取的浏览器（较新的 Firefox 或 Chromium）。Linux 下可双击运行，其他系统用命令行启动。
- 可选：`pdftotext`（poppler-utils），没有时读不了 pdf，其他格式不受影响。
- 一个 OpenAI 兼容的模型接口（接口地址、模型名、AK）。不需要访问其他网络，不需要安装第三方包。

## 使用方法

从 Releases 下载 `ask-local-files-v<版本>.zip` 并解压，双击「双击运行」，或运行 `python3 ask_local_files.py`。

页面宽度 900px 及以上时铺满浏览器窗口，分两栏：左栏「找文件」「已选」，右栏「问 AI」占满其余宽度和高度，约 3:7；窄屏为单列，开始对话后「找文件」收成一行，点「改选文件」展开。「＋ 新对话」在同一窗口里开新的对话标签，最多 8 个，各自选文件、各自对话。

1. 添加文件夹：第一次使用时自动展开「管理文件夹」。填文件夹路径（绝对路径、`~/` 开头，或从文件管理器地址栏复制的本机 `file:///` 地址）点「添加」，可以添加多个；也可以点「选择……」在系统的选择窗口里选（用 zenity、kdialog 或 tkinter 中找得到的一个）。输入路径时下拉列出子文件夹，下方给出本机存在的常用位置。添加后在后台扫描，扫描期间就能搜索。
2. 找文件分「浏览文件夹」「搜索」两个标签页，默认显示「浏览文件夹」，方向键可切换。
   - 浏览文件夹：从已添加的文件夹开始逐层查看，先列子文件夹（写明各层共含多少文件），再列本层文件（按修改时间从新到旧，最多 300 个）。进入某个文件夹后可以「全部加入」它和各层子文件夹里读得了的文件。
   - 搜索：输入文件名或路径里的字，边打字边出结果。多个关键字用空格分开，必须全部命中；扩展名框里填 `docx pdf` 只看这几类。勾上「正则表达式」时整个搜索框按一个正则表达式（Python 写法，不区分大小写）匹配。结果按修改时间从新到旧，最多 300 个；点结果里的文件夹名跳到「浏览文件夹」。按回车加入第一个结果，方向键在结果间移动。
   - 读不了的格式写明原因；压缩包等读不了的文件给「打开文件夹」，用 `xdg-open` 或 `gio open` 打开所在文件夹，打不开时写出路径并给「复制路径」。
   - 「从列表移除」只把一项从当前列表拿掉，不删文件、不影响已选，换关键字、进别的文件夹或点「刷新」后恢复。
   - 按文件名去重（默认勾上）：同名文件只列修改时间最新的一个，旁边写「另有 N 个同名」，点开可看其余同名文件并单独加入。同名指不区分大小写、扩展名相同，并且去掉一个副本标记（如「 (1)」「（2）」「 - 副本」「 copy」）后文件名相同。只影响列表和「全部加入」，不改索引，不动文件。
3. 已选：点「加入」，一次最多 50 个文件；列表里（去重与移除之后）少于 50 个时可以「全部加入」，只加读得了且还没加入的文件。已选按「1.」「2.」编号，与发给模型的「文件 N」一致。可以「预览」取出的文字、「移除」单个文件、「清空已选」。开始对话后再改动文件清单，直接开始新对话，并在状态行说明。
4. 问 AI：在输入框上方选模型，需要时选一个 skill（见下方「skill」），写要 AI 做什么，点「发送」或按 Enter（Ctrl+Enter 也可以），Shift+Enter 换行。回答逐字显示，按常见 Markdown 排版，可以接着追问，追问带着前面的问答和同一批文件。生成中可以「停止」；中断时保留已收到的部分，标「（回答不完整）」，并给「继续」（从断处接着写）和「重新生成」（用原问题重新请求）。
5. 摘句核对：模型须只依据所选文件回答，每个结论后附「（文件 N：「原文摘句」）」，找不到依据的写「所选文件中未找到」。回答结束后逐条核对摘句（忽略空白差异，省略号两侧分开核对），找不到的摘句列在回答下方；整条回答没附摘句时也会提示。这些提示一并写进保存的对话。
6. 每条回答可以「复制」「保存为 Word」；「保存对话」把文件清单和全部问答存成 `找文件问AI-年月日-时分.md`；「清空对话」点了直接清空，之后的提问是新对话。
7. 字数上限：页面上一直写着将发送到哪个接口主机、哪个模型、几个文件和字数。文件和对话合计超过「发送字数上限」（默认 10 万字）时先不发送，可以移除文件、调高上限，或「仍然发送」（按比例截断文件部分）。
8. 接口出错时写明原因和下一步：AK 无效或过期（401、403）、接口地址或模型名不对（404）、内容过长、请求太频繁或额度用完（429）。

支持的格式：

- 纯文本类直接读取：txt、md、csv、tsv、log、json、xml、yaml、ini、conf、sql 和常见代码文件，编码按 UTF-8、GB18030 识别，单个文件最多 20 MB；html、htm 去掉标签后取文字。
- docx、xlsx、xlsm、pptx、eml、pdf 由 `doc2kb_core.py` 转成文字；pdf 需要 `pdftotext`，扫描件取不出文字。
- 旧版 doc、xls、ppt（Office 97 及以后）同样由 `doc2kb_core.py` 取文字和表格；wps、et、dps 分别按 doc、xls、ppt 试读。有密码保护、更早版本或损坏的文件提示先另存为 docx、xlsx 或 pptx。
- 压缩包不读取，提示先解压，可点「打开文件夹」。其他扩展名按纯文本尝试，是二进制文件时提示不支持。
- 每个文件取出的文字开头先写路径、文件名、修改时间，文档里记录了作者时再写作者（和与作者不同的最后修改者），随正文一起发给模型。

## 索引与缓存

- 只索引添加的文件夹，跳过以 `.` 开头的文件和文件夹、`node_modules`、`__pycache__`，不跟随指向文件夹的链接；读不了的文件夹跳过并在状态里列出。
- 只匹配文件名和路径，不看文件内容。索引缓存在 `~/.cache/ask-local-files/index.json`（权限 600），启动即可搜索，后台只重扫修改时间变了的文件夹。点「刷新」立即检查，「重建索引」全部重扫。

## 模型接口与隐私

- 有 OpenCode 配置（`~/.config/opencode/opencode.jsonc` 或 `opencode.json`）时，列出其中带 `options.baseURL` 和 `options.apiKey` 的服务商下的全部模型；apiKey 可写成 `{env:变量}` 或 `{file:路径}`，服务商的 `headers` 一并带上。
- 也可以在「模型设置」里填接口地址、模型名和 AK，作为一项可选模型，「测试连接」可检查是否连通。设置存在 `~/.config/ask-local-files/config.json`（权限 600）。AK 不发给页面，日志不记 AK 和文件内容。
- 请求按 OpenAI 兼容的 `POST <接口地址>/chat/completions` 流式发送：系统消息写明摘句要求和所选文件，按「===== 文件 N：路径 =====」附上取出的文字，后面是对话。
- 文件文字和对话会发给你选的模型接口，请只选你有权交给该接口处理的文件。取出的文字只放在内存里，不写硬盘；对话只留在页面上，需要时点「保存对话」。

## skill

skill 是一个文件夹，内有 `SKILL.md`：开头两行 `---` 之间写 `name:` 和 `description:`，其后是给模型的说明；文件夹里还可以放参考文件和 `.py`、`.sh` 脚本（OpenCode 的 skill 格式）。「skill」下拉框列出工具目录 `skills/` 里预装的和 `~/.config/opencode/skills/` 里自建的，默认「不用 skill」。选了 skill 时可以不选文件，也可以不写问题直接发送；每条回答标明用了哪个 skill。

- skill 正文放在系统消息最前面，计入字数上限。选了文件时照常要求附原文摘句；依据脚本输出或参考文件得出的内容标「（脚本输出）」。
- skill 有参考文件或脚本时，请求按 OpenAI 兼容的函数调用（`tools`）附上工具，模型按需调用：
  - `read_skill_file`：读 skill 文件夹里的文本文件，单个最多 2 万字。
  - `run_script`：运行 skill 文件夹里的 `.py`（用运行本工具的 Python）或 `.sh`（用 bash），参数逐个传入、不经 shell。脚本从环境变量拿到 `ASK_FILES`（已选文件的路径，换行分隔）、`ASK_ROOTS`（已添加的文件夹）、`ASK_OUT`（本次运行的输出目录，写进去的文件可在页面上保存）、`ASK_WORK`（本问的工作目录）和 `ASK_TOOL_DIR`（工具目录，可借用 `doc2kb_core.py`）。
  - `write_work_file`：有脚本的 skill 才提供，把长内容写进 `ASK_WORK` 供脚本读取，单个文件最多 50 万字。工作目录每问新建，回答结束时删除。
  - 路径不能超出 skill 文件夹或工作目录（含经链接跳出）。
- 限制：脚本自动运行，不逐次确认；单次最多 60 秒；每问最多 5 次读取或运行、10 次写入；交给模型的工具结果最多 2 万字。点「停止」同时终止正在运行的脚本。模型接口不支持函数调用时写明原因，可改选只有说明的 skill 或换模型。
- 选用带脚本的 skill 即允许脚本以当前用户身份运行，能读写当前用户能访问的文件；只放来源可信的 skill。脚本输出会发给模型接口。

预装 skill：

| 名称 | 页面显示 | 用途 | 脚本 |
| --- | --- | --- | --- |
| `summarize-meeting` | 会议纪要 | 会议转写或记录 → 日期、参会人、要点、决定事项、待办、未决问题 | 无 |
| `doc-compare` | 文档对比 | 逐行比对两份已选文件，列出新增、删除、修改并归纳实质变化，可另存左右对照的 HTML 报告 | `scripts/compare.py` |
| `office-gen` | 生成 Word 与 Excel | 把整理好的内容生成 docx 或 xlsx，生成的文件可保存 | `scripts/make_docx.py`（Markdown → docx）、`scripts/make_xlsx.py`（JSON → xlsx） |
| `prompt-optimize` | 提示词优化 | 把原始提示词重写为简洁、明确、按编号分层的提示词 | 无 |
| `clarify-needs` | 需求澄清 | 任务描述笼统时先逐个提问摸清需求，问完给出需求摘要，确认后再执行 | 无 |

预装脚本只用 Python 3 标准库，也可以在终端单独运行（按上面的环境变量传入文件），带 `--help` 与 `--log-level`。`summarize-meeting` 原样复制自 [phuryn/pm-skills](https://github.com/phuryn/pm-skills)（MIT License），文件夹里附许可文件与 `UPSTREAM.md`。

## 双击运行与退出

首次双击时，文件管理器可能提示信任或询问运行方式，选允许运行即可；不允许时在「属性」→「权限」里勾选「允许作为程序执行」。放到桌面请用链接：`ln -s "$PWD/双击运行.desktop" ~/桌面/找文件问AI.desktop`，不要复制。

双击时优先用 Chromium 系浏览器的应用窗口模式（`--app`）打开，不显示地址栏；找不到时用默认浏览器的普通窗口。

服务只监听 127.0.0.1 的随机端口，网址带一次性令牌并校验 Host、Origin。点右上角「退出」立即结束；关闭页面约 5 秒后自动退出，页面挂在后台不影响；有回答正在生成或脚本在运行时等它结束再退出。日志写在程序目录下的 `ask_local_files.log`（目录不可写时写到 `~/.cache/ask-local-files/`）。

命令行：`python3 ask_local_files.py [--no-browser] [--no-app] [--log-level DEBUG|INFO|WARNING|ERROR]`，`--no-browser` 只打印网址，`--no-app` 用默认浏览器的普通窗口打开；日志级别默认 WARNING，可由环境变量 `LOG_LEVEL` 覆盖。

测试：`python3 -m unittest discover -s tests`；装有 Playwright 时 `node --test tests/ui.test.js`。
