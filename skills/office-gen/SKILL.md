# 生成 Word 与 Excel

文件由脚本生成：先用 write_work_file 把内容写进工作目录，再用 run_script 运行脚本，传入同样的文件名。不要在回答里贴出整份内容代替生成文件。

## 工具

- `scripts/make_docx.py 文件名.md [--out 名称.docx] [--title 文档标题]`：把 Markdown 写成 Word。支持 `#` 至 `######` 标题、段落（行内换行保留）、`**加粗**`、`*斜体*`、`` `代码` ``、`- ` 无序列表与 `1. ` 有序列表（缩进两格表示下一层）、`| 表格 |`（第二行为 `|---|` 分隔行）、`> ` 引用、``` 代码块、`---` 分隔线。其他写法按普通文字原样写入；不支持图片、页眉页脚和公式。
- `scripts/make_xlsx.py 文件名.json [--out 名称.xlsx]`：把 JSON 写成 Excel。格式为 `{"sheets": [{"name": "工作表名", "rows": [["表头1", "表头2"], ["文字", 123]]}]}`：
  - 每个工作表第一行是表头（加粗、冻结、可筛选）；不需要表头时在该工作表加 `"header": false`。
  - 数字写成 JSON 数字（不加引号），才能在 Excel 里计算和排序；`true`、`false` 为逻辑值；`null` 为空单元格。
  - 日期写成 `"2026-01-31"`，日期时间写成 `"2026-01-31 09:30"`，会存为 Excel 日期。
  - 编号、电话、证件号等前导 0 或很长的数字写成文字（加引号），如 `"001"`。
  - 不支持公式、合并单元格和颜色；以 `=` 开头的内容按文字写入。
- `write_work_file`：`path` 写文件名（如 `报告.md`、`数据.json`），`content` 写全部内容；内容很长、一次写不完时，第一次照常写，之后每次加 `"append": true` 接着写同一个文件。

## 步骤

1. 整理内容：依据已选文件和对话整理出要写的内容，事实照常附出处；出处写在文档正文里时按使用者要求的格式，没有要求时可以省略摘句，但回答里要说明依据哪些文件。
2. 写入：用 write_work_file 写 `.md`（Word）或 `.json`（Excel）。JSON 必须是合法 JSON，字符串里的双引号和换行要转义。
3. 生成：用 run_script 运行对应脚本，第一个参数是第 2 步的文件名；`--out` 写使用者能看懂的中文文件名，如 `--out 季度汇总`；Word 可加 `--title`。
4. 脚本输出「生成失败」时，按原因改正内容后重新写入、重新运行。
5. 回答：说明生成了哪个文件、包含哪些部分（工作表、行数或主要章节），提醒使用者在上方点「保存」。

## 注意

- 写入与运行各有次数上限：每个问题最多写入 10 次、运行 5 次；同时要 Word 和 Excel 时，两份内容各写一次、各运行一次。
- 生成的文件在临时目录里，服务退出时删除；需要留存的请使用者及时保存。
- 版式固定：A4、内置标题样式、正文宋体、标题黑体；使用者要求特殊版式时，生成后说明需要在 Word 里自行调整。
