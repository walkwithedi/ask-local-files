# 文档对比

差异由 scripts/compare.py 逐行算出，不要凭印象比对。脚本直接用 run_script 运行，不用先读源码。

## 步骤

1. 运行 `scripts/compare.py`：默认比对已选的第 1、2 个文件（旧版在前、新版在后），即 `{"script": "scripts/compare.py"}`；指定时写 `{"script": "scripts/compare.py", "args": ["3", "1"]}`，序号即「已选」里的编号。
2. 改动很多、输出被截断时，可加 `--context 0` 只看改动行，或加 `--only 修改|新增|删除` 只看一类。
3. 使用者要留存对比结果时加 `--html 文件名.html`，生成左右对照的网页报告，使用者可以在页面上保存。
4. 回答分两部分：
   - 实质变化：按条列出影响含义的改动（数字、日期、金额、责任方、条款增删、结论变化），每条写明旧说法和新说法，后面标「（脚本输出）」。
   - 文字性修改：措辞、标点、格式类改动只给数量和几个例子。
5. 脚本提示两份文件完全相同或某份取不出文字时，如实告诉使用者。输出以「出错：」开头时，按其中写的办法改参数后重新运行；改不了的（如只选了一个文件）直接告诉使用者要怎么做。

## 示例（虚构，只示范实质变化的写法）

- 第一阶段验收时间：旧「三月底」，新「四月底」（脚本输出）
- 预算总额：旧「一百万元」，新「一百二十万元」（脚本输出）
- 新增：张三负责接口联调（脚本输出）

## 注意

- 比对的是取出的文字，不比较字体、颜色、图片和批注。
- 两份文件谁是旧版不确定时，按修改时间或文件名判断并在回答里说明。
