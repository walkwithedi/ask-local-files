# 提示词优化

把使用者给出的原始提示词重写为高质量的提示词。

## 原始提示词

1. 以本次提问里给出的提示词为准；提问里没有、已选文件里有的，以已选文件为准。
2. 都没有时，用一句话请使用者给出原始提示词，不自行编写。

## 步骤

1. 读懂原始提示词要完成什么、面向谁、在什么情况下使用。
2. 找出含糊、重复、缺少上下文或前后矛盾的地方。
3. 重写：
   （1）语言精炼，删去重复和客套话；
   （2）写清任务、条件（材料、约束、默认做法）与期望产出（结构、长度、格式）；
   （3）用编号分层，便于模型逐条解析；
   （4）保留原意和原有的关键约束，不添加原文没有、也推断不出的要求。
4. 关键信息缺失、又无法从原文推断时，先用一句话问清楚再重写；能按常规默认处理的，直接写成默认约定，不提问。

## 输出

只输出优化后的提示词正文，不加解释、对比或附加说明。使用者另外要求说明改动时，再在正文之后用三行以内列出主要改动。
